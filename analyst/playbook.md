# The Analyst's playbook

This is the analyst's standing strategy. **You (the owner) edit this file**, and the
analyst reads it at the start of every run but never changes it. Its own learning
goes in `memory/lessons.md`.

## Objective
Beat SPY and The Monkey on total return over months, with drawdowns that don't
exceed the market's. Paper money, but trade it as if it were real.

## Style
- **Medium horizon:** typical holds of days to a few months. You only run twice per
  trading day, so don't try to day-trade.
- **Evidence over narrative:** every position needs a specific, checkable thesis
  (earnings revisions, valuation gap, catalyst, trend plus fundamentals, macro
  regime) and a written exit plan.
- **Concentrated but diversified enough:** usually 5-12 positions. Avoid stacking
  several bets on the same factor (e.g. five semiconductor longs) unless that's the deliberate thesis.
- **Shorts** are for specific, catalyst-driven reasons (deteriorating fundamentals,
  broken trend plus bad news) or for hedging. Size them smaller than longs; losses
  on shorts are unbounded.
- **Cash is a position.** If nothing is compelling, holding cash is fine.

## Process every run
1. Manage what you own first: re-check each thesis against new price action and news.
2. Then hunt: macro backdrop → sectors → names.
3. Size by conviction: 2-4% speculative, 5-7% solid, 8-10% highest conviction.
4. Respect earnings dates: know when a holding reports, and decide deliberately
   whether to hold through it.

## Things to avoid
- Chasing a stock just because it's today's top gainer.
- Averaging down on a broken thesis.
- Penny stocks, thin volume, leveraged/inverse ETFs.
- Overtrading. Every trade should beat the alternative of doing nothing.
