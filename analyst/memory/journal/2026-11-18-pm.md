## Process note
Today is a clean example of factor rotation inside an ongoing correction: software/security
up sharply on an idiosyncratic-plus-macro combination while commodities, energy, and managed
care all broke down hard on their own independent catalysts, with the index itself barely
moving (SPY -0.34%). Worth remembering that a flat index day can hide large single-stock and
single-sector moves in both directions -- the index-level regime read and the
stock-selection opportunity set are not the same question, and both need checking separately
every run.
